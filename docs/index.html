Add a video skill to Claude in under a minute

Each skill is a single SKILL.md file. Works in the Claude app (web and desktop) and in Claude Code.

  1. Download a skill. On GitHub, open any skill folder, open its SKILL.md, then ••• › Download.
  2. Open your skills. In Claude: + › Skills › Manage skills.
  3. Upload it. Add › Upload skill, drop the SKILL.md, check its name and description, click Upload.
  4. Ask for a video. Type / and the skill's name, then what you want.
/event-promo 20-second promo for our Design Systems Meetup:
Thu 12 Nov, 7 pm, Lisbon. Free tickets at meetup.example
--motion:high

In Claude Code

git clone https://github.com/Neelshah1810/Claude-Video-Skills
mkdir -p ~/.claude/skills

The 11 Claude video skills

Each skill works for any brand, product or idea, with eight style presets and four creative dials: --creativity, --typography, --animation and --motion.

SkillUse it for
motion-filmAny motion-graphics video: title sequences, promos, kinetic typography
launch-filmProduct, feature and company launches, announcements, teasers
product-walkthroughProduct tours, demos, onboarding, screen walkthroughs
explainer-video“How it works” and “what is X” explainers, process and concept videos
tutorial-videoStep-by-step how-tos, help-centre videos, training
feature-updateWhat’s new, release notes, changelog videos
data-storyYear-in-review, “wrapped”, KPI and impact reports, investor updates
brand-filmManifestos, mission and values films, rebrands, logo stings
event-promoConferences, webinars, meetups, launches, countdowns

FAQ

What are Claude Video Skills?

A free, open-source set of 11 Claude skills that turn Claude into a video studio. Describe a video in plain words and Claude makes a finished motion-graphics film, with kinetic typography, animated UI, charts, transitions and its own music, as an HTML file and an MP4.

Do I need to know video editing or code?

No. Describe the video in plain words. Claude writes the code, renders it and checks every frame for you.

Do they need an API key or a paid video tool?

No. Everything runs with Claude's code execution, Chrome and FFmpeg. The music is synthesized in the film itself. ElevenLabs is only an optional way to add a voiceover.

Which Claude model works best?

Any recent model works, but these skills work best with Claude Opus 5.5.

Can it use my brand, and make vertical videos?

Yes. Share your brand guide, logo and site, and Claude designs to them. The social-ad skill makes 1080×1920 videos for Reels, TikTok and Shorts.
