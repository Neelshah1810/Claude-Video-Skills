01 · How to use

Add a skill to Claude in under a minute.

Each skill is one SKILL.md file. Upload it once, then ask for videos in any chat.

Fig. 1 · Adding the event-promo skill to the Claude app, about 30 seconds
  1. Download a skill. Open any skill folder on GitHub, open its SKILL.md, then ••• › Download.
  2. Open your skills. In Claude: + › Skills › Manage skills.
  3. Upload it. Add › Upload skill, drop the file, check its name and description, then Upload.
  4. Ask for a video. Type / and the skill’s name, then what you want. 
    /event-promo 20-second promo for our
Design Systems Meetup: Thu 12 Nov,
7 pm, Lisbon. Free tickets at
meetup.example --motion:high

In Claude Code

Copy a skill into your skills folder, then run it with /skill-name or just ask.

git clone https://github.com/Neelshah1810/Claude-Video-Skills
mkdir -p ~/.claude/skills
cp -R Claude-Video-Skills/event-promo ~/.claude/skills/
# then, in Claude Code:
/event-promo make a 20-second promo for …

03 · The skills

Pick the one that fits the video.

Every skill works for any brand, product or idea, with eight style presets and four creative dials.

  • motion-filmTitle sequences, promos, kinetic typography
  • launch-filmProduct, feature and company launches
  • product-walkthroughProduct tours, demos and onboarding
  • explainer-video“How it works” and concept explainers
  • tutorial-videoStep-by-step how-tos and training
  • feature-updateWhat’s new and release notes
  • data-storyYear-in-review and KPI reports
  • brand-filmManifestos, rebrands and logo stings
  • event-promoConferences, meetups and countdowns
  • testimonial-videoCustomer quotes and case studies
  • social-adReels, TikTok and Shorts (9:16)

Tune any film with --creativity, --typography, --animation and --motion (low, medium or high). Your brand guide always wins.

04 · Questions

Good to know.

What are Claude Video Skills?
A free, open-source set of 11 Claude skills that turn Claude into a video studio. Describe a video in plain words and Claude makes a finished motion-graphics film as an HTML file and an MP4.
Do I need to edit video or write code?
No. Claude writes the code, renders the film and checks every frame. You describe what you want and give feedback by timestamp.
Do they need an API key or a video tool?
No. They run on Claude’s code execution with Chrome and FFmpeg, and the music is synthesized in the film. ElevenLabs is only an optional way to add a voiceover.
Which model works best?
Any recent Claude model works; they work best with Claude Opus 5.5.
Can it use my brand?
Yes. Share your brand guide, logo and site, and Claude designs to them. Your brand always overrides the presets.
Vertical videos?
Yes. The social-ad skill makes 1080×1920 films that respect each platform’s safe zones.
If these skills help you, star the repo on GitHub. It helps other people find it.
